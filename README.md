# tenpo-release（店舗運営/MDの辞書・画面の枠）

このリポジトリは **GitHub Pages で配る「画面の枠」だけ**です。

- 🔴 **辞書の中身（判断カード・運営の型・催事・教科書・スライド・天気の知見）は、ここに置きません。**
  中身は GAS が、会社の Google アカウントかを毎回確かめてから返します。
- 公開の場所に中身を置くと、ログインを丸ごと迂回する裏口になります（一時的なプレビューでも禁止）。
- ここにあるファイルは、辞書の台本（`build.py`）が作ります。**手で直さない**でください（次に作ると上書きされます）。
- 作るときは、中身の文や社内の名前が紛れ込んでいないかを台本が検査し、見つかったら何も書かずに止まります。
