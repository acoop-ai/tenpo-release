# tenpo-release（店舗運営/MDの辞書・画面の枠）

このリポジトリは **GitHub Pages で配る「画面の枠」だけ**です。

- 🔴 **辞書の中身（判断カード・運営の型・催事・教科書・スライド・天気の知見・店ごとの数）は、ここに置きません。**
  中身は GAS が、会社の Google アカウントかと役目（店・本部・管理者）を毎回確かめてから返します。
- 公開の場所に中身を置くと、ログインを丸ごと迂回する裏口になります（一時的なプレビューでも禁止）。
- いちばん上の `index.html`・`style.css`・`boot.js`・`auth.js`・`status.js`・`search_norm.js`・`config.js`・`ver.js`（いまの版の字だけ。開いている画面が新しい版に気づくため）は、画面「ステータス」。開発側の台本（`build_release.js`）が作ります。**手で直さない**でください（次に作ると上書きされます）。
- `classic/` は前の辞書の画面（V0.5）。辞書の台本が作り、この台本が写します。
- 作るときは、中身の文や社内の名前が紛れ込んでいないかを台本が検査し、見つかったら何も書かずに止まります。
- `video/` は画面「AI教材の動画」。動画と字幕はここに置きません。
- `reports/` は画面「分析レポート」。レポートの中身・題はここに置きません（窓口がログインを確かめてから返し、砂箱の中で開きます）。
- いちばん上の `app.js` は前の画面の残り（古い写しを持つ端末のため）。次の公開で外します。
